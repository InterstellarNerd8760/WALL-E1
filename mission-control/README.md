# Mission Control

Ground dashboard for WALL-E1. Design owned by Weston.

Open `index.html` in a browser. No build step.

This snapshot is a **simulated** flight: Fair Oaks launch, BME280-shaped telemetry, LoRa packet log, SpotTrace-shaped track. Live Pico / SX1262 / FindMeSPOT feeds are not wired yet.

## Controls

- Pause / Resume
- 10× time accel
- Reset
- Keys: `space` pause, `f` 10×, `r` reset
